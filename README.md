This repository contains the computational workflows and scripts for genome-scale metabolic model (GEM) reconstruction and microbial metabolic interaction analysis of microorganisms in sauce-flavor Daqu. The workflows integrate metagenomic data processing, metagenome-assembled genome (MAG) reconstruction, functional annotation, metabolic model reconstruction, and metabolic exchange analysis to investigate the metabolic potential and potential cross-feeding interactions among Daqu-associated microorganisms.
